## Key Metrics

| Metric | Description |
|--------|-------------|
| Model latency | Time to generate predictions |
| Model accuracy | Quality of predictions |
| Model drift | Change in model performance over time |
| Data drift | Change in input data distribution |
| Throughput | Predictions per second |

## Deployment Strategies

| Strategy | Description |
|----------|-------------|
| Blue-Green | Two identical environments, swap traffic |
| Canary | Gradually roll out to subset of traffic |
| Shadow | Run new model alongside old, compare results |

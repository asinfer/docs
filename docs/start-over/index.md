The project must preserve failures.

## Start-Over Protocol

```text
                    Current System
                         │
                         ▼
                    Measure
                         │
                         ▼
                   Find Bottleneck
                         │
                         ▼
                 Challenge Assumption
                         │
                         ▼

                         │
                  ┌──────┴──────┐
                  │             │
                Better        Worse
                  │             │
                  ▼             ▼
               Adopt       Document Failure
                  │             │
                  └──────┬──────┘
                         ▼
                    Start Again
```

## The Goal

> **The goal is not to avoid failure. The goal is to make failure compound into expertise.**

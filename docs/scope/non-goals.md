# Non-Goals

> **Deep Anchor** - Research / Mastery / Systems

## What We Are NOT Building

The project has explicit non-goals to maintain focus.

### Excluded

| What | Why Not |
|------|---------|
| Another general-purpose LLM | Not our expertise, not our focus |
| Another generic chatbot | The value is in the routing, not the chat |
| Another vector database | We use existing databases, not build new ones |
| Another AI agent framework | We orchestrate agents, not build frameworks |
| Another API gateway | We are an inference system, not infrastructure |
| A giant enterprise platform | Start small, prove value, then scale |

## The Focused Question

> **How much intelligence can be avoided while preserving answer quality?**

This question excludes:

- Building new foundation models
- Creating general-purpose AI assistants
- Building developer platforms
- Enterprise feature parity

## What This Means

```text
We are NOT building:
├── A new GPT
├── A new ChatGPT
├── A new Pinecone
├── A new LangChain
├── A new Kong/NGINX
└── A new Salesforce

We ARE building:
├── An inference router
├── A semantic cache
├── A complexity evaluator
├── A knowledge compressor
└── A production API
```

## Scope Boundaries

### In Scope

- Inference optimization
- Semantic caching
- Model routing
- Knowledge compression
- Production API

### Out of Scope

- Model training
- Data collection
- User interface (beyond API)
- Mobile applications
- Hardware optimization

## Why Non-Goals Matter

Without explicit non-goals, scope creeps. The project would attempt to:

- Build a better embedding model
- Create a new vector database
- Design a chat interface
- Implement user management
- Build analytics dashboards

Each of these is valuable. None of them are necessary for the core hypothesis.

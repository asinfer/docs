# Engineering Principles

> **Deep Anchor** - Research / Mastery / Systems

## Core Principles

### 1. Measure Before Optimizing
No performance claim without a benchmark.

### 2. Cache Before Compute
Always ask whether the answer already exists.

### 3. Cheap Intelligence Before Expensive Intelligence
Prefer the cheapest model that can answer correctly.

### 4. Every Expensive Computation Should Create Reusable Knowledge
Frontier inference should feed the knowledge layer.

### 5. Public Proof Beats Private Claims
Prefer evidence over assertions.

### 6. Simplicity Is a Performance Feature
Every component adds latency, cost, and failure modes.

### 7. Start Over Deliberately
A failed architecture should become documentation, not hidden history.

## Hierarchy

```text
Measurement → Caching → Cheap Intelligence → Knowledge Reuse → Public Proof → Simplicity → Restart
```
